# U3: Vocet design tokens in the app and on the website

**DS1 approved by the owner on 2026-11-03.**

Build spec from the Design Lead, 2026-11-03.

Source of truth: docs/design/design-system/tokens.css, plus index.html for the components. All text/background pairs are checked at ≥ 4.5:1 in light and dark mode.

## Why

Today the app and the site look like two products:
- **Blue:** the app uses #0A66D6, the site #1F4FC9.
- **Tokens:** the app's settings.css has its own variables; the overlay has hard-coded colours.

One token file keeps the app, the site and later Notes / Read Aloud consistent (Claude 7; Codex top-10 #9).

## Acceptance criteria

1. [auto] `src/styles/tokens.css` is a copy of DS1's tokens.css (header comment: "Source: design-system/tokens.css, DS1"), imported once by the main window and the overlay entry points. A test or lint step fails if a stylesheet in `src/` uses a hex colour outside tokens.css (exceptions listed in one place with reasons).
2. [auto] settings.css, the onboarding, Troubleshoot, HotkeyRecorder and overlay styles use only `--vc-*` variables for colour, radius, spacing and type size. The app keeps the system font (`--vc-font-ui`). Dark mode follows the system through the tokens' `prefers-color-scheme` block.
3. [auto] Components match DS1:
   - **Buttons:** primary, secondary, plain and destructive; 28 px in Settings, 44 px for onboarding primaries.
   - **Keycap** style (shared with U2).
   - **Chips:** ready, info, attention, error, always with a symbol or word as well as colour.
   - Grouped settings rows and the switch.
   - Focus rings: 3 px accent outline with 2 px offset on every interactive element.
4. [auto] Literal overlay colours from U4 are replaced by `--vc-overlay-*`, `--vc-recording` and `--vc-meter*`, with no visual change.
5. [auto] The website (`site/index.html`) uses the same tokens: inline tokens.css (no build step) with `class="vc-site"` on `<html>`, and its `:root` variables map to `--vc-*` (or are replaced). It keeps Inter / Inter Tight via the `.vc-site` font override. The page renders the same apart from the shared values; the PR includes before/after screenshots at 1440 and 390 px.
5b. [auto] The website serves Inter and Inter Tight **from vocetlabs.com itself**: WOFF2 files in `site/fonts/` (only the weights used: 400/500/600/700 and Tight 700/800, Latin plus Latin-ext subsets) with `font-display: swap`. Remove the fonts.googleapis.com/fonts.gstatic.com links, so the page makes no third-party requests apart from api.github.com for the release lookup. Credit the fonts' SIL OFL licence in `site/fonts/LICENSE.txt` and NOTICE. (Lead's suggestion, accepted: it matches the privacy message.)
6. [auto] `prefers-reduced-motion` removes transitions and animations app-wide (tokens set the durations to 0).
7. [manual] In the VM, in light and dark mode: Settings, onboarding, Troubleshoot and the pill side by side with the DS1 page. Screenshots go on the PR, and the Design Lead posts "Design Lead: OK" or "Design Lead: CHANGES".

## Out of scope

- Layout changes (U6, U8).
- The app icon artwork (the draft is in DS1; the final icon comes later).
