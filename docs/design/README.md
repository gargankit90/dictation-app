# Design source

Vocet's design work: the design system, build specs and reviews, kept here so it has history and a backup. Working copies live with the Design Lead and are synced here.

- `design-system/`: `tokens.css` (the source for `src/styles/tokens.css` and the copy in `site/index.html`), `index.html` (the components, light and dark), `tray/` (menu-bar icons), and `u11-mock.html` with its build script. Open the HTML files in a browser.
- `specs/`: build specs by milestone. The Lead copies each to `docs/history/milestones/<id>.md` when work starts, and that copy is the one Developers build from. `specs/U9.md` was built as **U12**, because the Lead's U9 is the setup blockers.
- The original landing page and setup boards from rounds 1 and 2 aren't here: they need the design tool's runtime and images to open, and they were early explorations under placeholder names. `specs/U8.md` still refers to them. The Design Lead keeps a copy.
- `reviews/`: Design Lead reviews of the running app.

Specs record what was decided when they were written. For what the app does now, read the code and `docs/privacy.md`.
