# M4.1: paste flow and clipboard

## Goal

Insert text by paste, then restore the user's clipboard safely.

## Scope

- `platform::insert::mod`: save clipboard → write text with `TransientType`/`ConcealedType`/`AutoGeneratedType` markers and our session marker → send the paste chord → restore only if our marker is still there.
- `platform::insert::macos`: Cmd+V with the layout-aware V key.

## Out of scope

- Secure Input skip (M4.2). Windows chord (M-W.2).

## Acceptance criteria

1. `[auto]` With fakes: the clipboard is restored when unchanged and left alone when something else changed it.
2. `[auto]` With fakes: clipboard writes carry all three markers.
3. `[auto]` The right chord is chosen for the OS and layout.
4. `[manual]` Paste into TextEdit works; a clipboard manager (e.g. Maccy) doesn't record the transcript.

Every milestone also needs: the gate green, coverage at or above thresholds, `Tester: PASS` and `Reviewer: APPROVED` on the PR.
