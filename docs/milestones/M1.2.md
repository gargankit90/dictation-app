# M1.2: ports and fakes

## Goal

Define the boundaries to the OS and network as traits, with fakes for tests.

## Scope

- `ports`: `HotkeySource`, `AudioSource`, `Transcriber`, `TextInserter`, `Clipboard`, `SecretStore`, `Permissions`, `Clock`. Document the async approach chosen (native `async fn` in traits or boxed futures) and why.
- `platform::fakes` behind feature `testing`: `FakeHotkey` (scripted presses), `FileAudioSource` (reads a WAV), `FakeInserter` (records text), `MemClipboard`, `MemSecretStore`, `FakePermissions`, `FakeClock`.

## Out of scope

- Real OS adapters.

## Acceptance criteria

1. `[auto]` `ports` builds with no `cfg(target_os)` and depends only on `core`.
2. `[auto]` Each fake has self-tests showing it behaves as its trait documents (e.g. `MemClipboard` round trip, `FakeHotkey` emits events in order).
3. `[auto]` Fakes compile only with feature `testing`.
4. `[auto]` Every trait method has a doc comment stating errors and threading expectations.

Every milestone also needs: the gate green, coverage at or above thresholds, `Tester: PASS` and `Reviewer: APPROVED` on the PR.
