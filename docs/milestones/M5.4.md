# M5.4: DMG, tester README and updater

## Goal

Something we can hand to alpha testers.

## Scope

- DMG signed with `dictation-app Dev` (not notarised).
- Tester README: install, clearing quarantine, permissions, getting a Groq key, sending logs.
- Updater plugin with a minisign key, served from GitHub Releases.

## Out of scope

- Developer ID signing and notarisation (needs the Apple account).

## Acceptance criteria

1. `[auto]` CI builds the DMG as an artifact.
2. `[manual]` Clean install in a freshly restored VM following only the README: quarantine, permissions, first dictation.
3. `[manual]` Updating to a newer build keeps Accessibility and Microphone permission.
4. `[manual]` The updater finds and installs a newer test release.

Every milestone also needs: the gate green, coverage at or above thresholds, `Tester: PASS` and `Reviewer: APPROVED` on the PR.
