# M2.2: microphone capture

## Goal

Record real audio from the mic at 16 kHz mono.

## Scope

- `platform::audio` using `handy-recorder` / cpal: ring buffer, resample to 16 kHz mono, nothing blocking the callback.
- Microphone permission check.
- `--debug-audio-file <wav>` uses `FileAudioSource` instead of the mic (test hook).
- Mic warm-up and Bluetooth route handling at start (ideas from Muesli, MIT).
- Measure press-to-first-sample latency and log it at debug level.

## Out of scope

- Transcription. Audio written to disk outside debug mode.

## Acceptance criteria

1. `[auto]` With `--debug-audio-file`, the pipeline receives the file's samples (integration test).
2. `[auto]` Resampling 48 kHz → 16 kHz keeps duration within 1%.
3. `[manual]` Record → save (debug mode) → play back sounds right with the built-in mic.
4. `[manual]` Same with AirPods; switching input mid-session doesn't crash.
5. `[manual]` Latency figure recorded in the PR notes.
6. `[manual]` Without mic permission, a clear error is shown.

Every milestone also needs: the gate green, coverage at or above thresholds, `Tester: PASS` and `Reviewer: APPROVED` on the PR.
