# M3.2: OpenAI-compatible cloud transcription

## Goal

Transcribe with Groq or OpenAI using the tester's own key.

## Scope

- `transcribe::openai_compat`: multipart `/audio/transcriptions` with `reqwest`; Groq and OpenAI presets (base URL, model).
- `verbose_json` responses; keep `no_speech_prob` per segment for the hallucination filter.
- Error mapping: 401 → InvalidKey, 429 → RateLimited (retry), 5xx → retry then fail, timeout, malformed JSON.
- Confirm Groq's current upload limit and record it in `docs/ENGINEERING.md`.

## Out of scope

- Keychain storage (M3.3). Local models.

## Acceptance criteria

1. `[auto]` wiremock: request carries file, model and language fields.
2. `[auto]` wiremock: 200 parses text and `no_speech_prob`.
3. `[auto]` wiremock: 401 → InvalidKey; 429 → RateLimited then retry; 5xx → retry then fail; timeout; malformed JSON → error.
4. `[auto]` The API key never appears in logs or error messages (test asserts on captured logs).
5. `[auto]` `transcribe` coverage ≥ 85%.

Every milestone also needs: the gate green, coverage at or above thresholds, `Tester: PASS` and `Reviewer: APPROVED` on the PR.
