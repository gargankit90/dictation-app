# M5.2: onboarding

## Goal

Walk a first-time tester from install to a working dictation.

## Scope

- Steps: Microphone permission → Accessibility permission → provider and key (with Test) → try a test dictation.
- Each step moves on only when its condition is met; can be reopened from the tray.

## Out of scope

- Account systems of any kind.

## Acceptance criteria

1. `[auto]` Vitest: each step advances only when its condition is met (mockIPC).
2. `[manual]` In a freshly restored VM, onboarding takes a new user to a working dictation.

Every milestone also needs: the gate green, coverage at or above thresholds, `Tester: PASS` and `Reviewer: APPROVED` on the PR.
