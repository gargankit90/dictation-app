# M1.3: pipeline with fakes

## Goal

Run the coordinator against the ports in `app::pipeline`, proven with fakes only.

## Scope

- `app::pipeline`: tokio runtime; feeds port events into `step`, carries out commands, emits UI events (state changes, errors) through a channel.
- A test-only transcriber returning fixed text (the real mock lands in M3.1).

## Out of scope

- Tauri. Real OS adapters.

## Acceptance criteria

1. `[auto]` Integration test: press → release → the fake inserter receives the transcript.
2. `[auto]` UI events arrive in order: Recording, Transcribing, Inserting, Idle.
3. `[auto]` Transcriber error → error event, no insert, back to Idle.
4. `[auto]` Cancel during recording → no transcribe call, no insert.
5. `[auto]` Two dictations back to back both insert, in order.
6. `[auto]` `app` coverage ≥ 70%; `app` has no Tauri dependency.

Every milestone also needs: the gate green, coverage at or above thresholds, `Tester: PASS` and `Reviewer: APPROVED` on the PR.
