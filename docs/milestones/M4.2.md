# M4.2: Secure Input skip and text cleanup

## Goal

Don't paste into password fields; clean up transcripts.

## Scope

- Skip pasting while Secure Input is on, with a user-facing message.
- `core::text`: trim, smart leading space, drop empty results, and drop Whisper-on-silence phrases ("Thank you.", "you") only when `no_speech_prob` also says there was no speech.

## Out of scope

- LLM cleanup (later).

## Acceptance criteria

1. `[auto]` Secure Input on → no paste, an error event, back to Idle (fakes).
2. `[auto]` `text` unit tests: trimming, leading space, empty results, hallucination filter with and without high `no_speech_prob`.
3. `[manual]` With a password field focused, dictation doesn't paste and shows the message.

Every milestone also needs: the gate green, coverage at or above thresholds, `Tester: PASS` and `Reviewer: APPROVED` on the PR.
