# M1.5: Tauri shell: tray, single instance, test CLI

## Goal

A running app in the menu bar that test scripts can drive.

## Scope

- Tray icon with Quit (and a disabled Settings item for now).
- Single-instance plugin; a second launch forwards its CLI flags to the running app.
- CLI flags `--press` / `--release` feed synthetic hotkey events (test hooks).
- Pipeline wired with real hotkey and fakes for audio, transcriber and inserter.
- `tests/e2e/` harness: build, copy into the VM, launch, run a scenario, collect logs.

## Out of scope

- Real audio, transcription and paste.

## Acceptance criteria

1. `[auto]` `e2e_startup` in the VM: the app launches; a second launch with `--press` forwards the flag and doesn't open a second app.
2. `[auto]` `--press` then `--release` produces the full state sequence in the log (fakes).
3. `[manual]` Tray icon appears; Quit exits cleanly.

Every milestone also needs: the gate green, coverage at or above thresholds, `Tester: PASS` and `Reviewer: APPROVED` on the PR.
