# U12: simpler Settings and menu bar

From the owner's run on a real Mac, with the Design Lead's tokens and details
(`design-review-main.md` items 1-11, spec `specs/U9.md`, whose U9 is this U12).
Where they differ, the owner's decisions below win. Closes #277.

## Bugs

1. [auto] #277: from Help, Troubleshoot… then Back to Settings returns to Help, even after the tray opened History earlier. Same for Report a problem. A test fails without the fix.
2. [auto] Troubleshoot and Report a problem are different screens. Troubleshoot has the checks and fixes only, and links to Report when a check fails. Report has its own screen with the report preview and its save, copy and open actions, and Back returns to where it came from. Each window title matches its screen ("Vocet Troubleshoot", per U1 criterion 1). The raw code such as (key_missing) moves behind a Details disclosure and stays in the report. Wording: "Dictation key", "Speech engine".

## Speech

3. [auto] Speech is one pick-one list, as below. Selecting a row chooses the engine, replacing the Downloaded badge, Use this, Active and Hide. A not-yet-downloaded row shows Download and its size, plus progress and pause or cancel while downloading, and can't be selected until ready. Keep all existing states: loading, failure, paused, and selection blocked with a reason. Delete stays in the "..." menu of a downloaded row. Plain names lead: "English", and a count generated from `language_codes` ("30 languages") in one place in the code, not "All languages", which the catalogue can't back (Design Lead; the owner is deciding); model names go on a smaller line or in that menu.

   ```
   Speech engine
   (•) English        On this Mac · works offline   ...
   ( ) 30 languages   On this Mac · works offline   Download · 590 MB
   ( ) Your own key   About 100 languages · uses internet   Change key…
   ```

   Owner-approved wording: once a key is saved, "Your own key" reads "Groq · about 100 languages · speech is sent to Groq", with the saved provider's name. Never "All languages" or "100+"; "30" comes from `language_codes`.

4. [auto] "Change key…" opens a native-feeling sheet with: a compact Provider popup in a normal row (no gradient), the short how-to, the key field, Test & Save and Remove key at matching sizes, and Done. It shows one status line only: "✓ Connected · saved in Keychain" after a test, otherwise "A key is saved in your Keychain." Selecting "Your own key" with no key opens the sheet and doesn't switch the engine until a key works. Existing key-race protections in `src/settings/ownKey.tsx` stay.

## Dictation

5. [auto] The row shows the key's keycap with one "Change…" button beside it, on one line at the minimum window size. Recording shows "Press a key…" with Use default and Cancel. Reset to default is no longer a permanent button in Settings. Setup's Try it screen doesn't change (U11 handles it), so the shared recorder has an option rather than a behaviour change for setup.
6. [auto] "Dictation key" replaces Shortcut and hotkey in all user-facing text in Settings, Troubleshoot, the menu and errors. The log lines the e2e scenarios match stay, and scenarios that read changed UI text are updated.

## Menu bar

7. [auto] The menu is exactly:

   ```
   ✓ Ready · Hold <key>
   ---
   Copy last dictation
   History…
   ---
   Settings…   ⌘,
   Help…
   ---
   Quit Vocet  ⌘Q
   ```

   The Groq line, Troubleshoot…, Report a problem… and Check for updates… are gone. Help… opens Settings → Help. Check for updates stays in Settings → General, and an update-found path that relied on the old item keeps working. The attention state still shows its fix row (for example "Open Speech settings…"), and the states in `e2e_tray_menu_screenshots` stay covered. While an on-device model is downloading and it's the chosen engine, the menu shows that rather than "! No API key saved." (Design Lead item 11).

## Polish

8. [auto] Tokens from the Design Lead: dark primary buttons and sidebar selection are calmer. `--vc-primary-bg`, `--vc-primary-hover` and `--vc-primary-fg`, with setup's navy for the Settings sidebar selection in dark. Light stays unchanged. Contrast passes in both.
9. [auto] The selected sidebar row's focus ring is drawn inset and no longer runs into the next row, and keyboard focus stays visible.
10. [auto] About's links are styled like native controls, without web underlines. Nothing else changes there.
11. [auto] The Keychain notice shows only where it's relevant and isn't green on every section.
12. [auto] Help and History don't repeat a row label in its button, for example the row is "Troubleshoot" with the button "Open…", and Clear history is one destructive control. The Run setup again caption lists steps in the real order: speech, permissions and a test.
