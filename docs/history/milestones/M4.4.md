# M4.4: real Groq end to end

## Goal

Real transcription through Groq, plus manual checks in everyday apps.

## Scope

- Real provider wired in; mock stays selectable.
- Opt-in e2e tests that need `GROQ_API_KEY` (passed into the VM only for this run, never written to disk in the repo).

## Out of scope

- Other providers beyond Groq/OpenAI.

## Acceptance criteria

1. `[auto]` `e2e_real_groq` (opt-in): a `say`-generated WAV transcribes to text that fuzzily matches.
2. `[auto]` `e2e_error_bad_key`: an invalid key shows an error, pastes nothing, and the app stays usable.
3. `[manual]` Dictate into Slack, Chrome, VS Code and Terminal on the Mac; record results in the PR.

Every milestone also needs: the gate green, coverage at or above thresholds, `Tester: PASS` and `Reviewer: APPROVED` on the PR.
