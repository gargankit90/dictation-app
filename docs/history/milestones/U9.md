# U9: setup can't get stuck, and its broken states are fixed

The owner found these by running setup on a real Mac after clearing Vocet's
permissions.

## Acceptance criteria

1. **[auto]** With Accessibility not granted, both step 2 routes go forward:
   Download and continue starts the download and moves to Permissions, and the
   own-key route's Continue moves to Permissions. A hotkey that's only waiting
   for Accessibility isn't a failed save. Settings still tells the user about
   it.
2. **[auto]** Step 2 never shows the "can't listen to the keyboard" message. No
   user-facing text anywhere shows the raw name `RightAlt` or other internal
   key specs; it uses the keycap label.
3. **[auto]** A new e2e scenario runs setup from a clean first launch with no
   Accessibility and no microphone permission, through step 2 on the download
   route, using a mock or fixture so it doesn't need a real download if one
   exists. It fails without the fix for 1. If the VM can't start without
   Accessibility, the PR says so and 1 is covered by the closest test that does
   fail without the fix.
4. **[auto]** The selected English/Hindi/More button keeps its filled background
   and readable label in every state: focused, hovered, pressed, after a click,
   and after the window loses focus, in light and dark.
5. **[auto]** On Try it, the whole failed-paste panel including its button can be
   reached and is scrolled into view at the default size and at the 680x520
   minimum, in the owner's state: a recorded two-key shortcut and the panel
   open. `e2e_onboarding_layout` enforces it.
6. **[auto]** On Try it, focus returns to the text box after recording a new key,
   after cancelling a recording, and when the window becomes active again. The
   first dictation works without clicking. The text box stays empty and focus
   isn't stolen while a recording is in progress.
7. **[auto]** The language search box in setup and Settings → Dictation → Language
   uses the design tokens: the standard rounded focus ring, no list row clipped
   under the field, and a closed state that reads as a picker with a chevron. It
   works at 680x520 and with the keyboard.
