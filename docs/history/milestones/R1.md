# R1: Releases in this repo

## Goal

Releases went to a separate public repository,
`gargankit90/dictation-app-releases`, only because this source repository was
private. It has been public since 2026-11-02 and no release has been published
yet (no installed copy's updater can break), so releases are published in
`gargankit90/dictation-app` itself, before 0.1.0.

## Acceptance criteria

1. **[auto]** The updater endpoint is
   `https://github.com/gargankit90/dictation-app/releases/latest/download/latest.json`
   (`src-tauri/tauri.conf.json`), and the updater's download-URL allowlist in
   `src-tauri/src/updater.rs` accepts only
   `https://github.com/gargankit90/dictation-app/releases/download/...` (the old
   repository's URLs and lookalikes such as `dictation-app-releases`,
   `dictation-app.evil`, `http://`, other hosts, path tricks like `/../` and
   URL-encoded slashes are rejected). Unit tests cover each, and fail if the
   allowlist is loosened back.
2. **[auto]** `scripts/release.sh` publishes to `gargankit90/dictation-app`:
   `gh release create v<version>` targets the exact commit it built, which must
   be reachable from origin's default branch with a clean tree (refuse
   otherwise); the release tag `v<version>` must not exist yet (tags are
   immutable here: a ruleset blocks moving or deleting them, so a failed
   publish needs a new version, and the error says so); the existing
   version/format guards (PR #171) stay. `latest.json`'s URLs point at this
   repository. `scripts/test-release.sh` is updated with fake tools only (never
   a real publish) and covers the new refusals.
3. **[auto]** Docs: `docs/releasing.md`, `docs/TESTERS.md` (download link
   `https://github.com/gargankit90/dictation-app/releases/latest`),
   `docs/ENGINEERING.md`, README if it links releases. The old repository is
   mentioned only as "archived, never used for a release".
4. **[auto]** No secret or key handling changes: the updater private key and
   password stay only in the owner's Keychain (services
   `dictation-app-updater-key` / `dictation-app-updater-password`), never read
   by tests; the public key `F6C80F173A96D78F` is unchanged.
5. **[manual]** The owner archives `gargankit90/dictation-app-releases`
   (Settings -> Archive) after this merges; the owner runs the first real
   release (`scripts/release.sh 0.1.0 --publish`).
