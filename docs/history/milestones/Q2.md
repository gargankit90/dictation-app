# Q2: Cleanup in the pipeline, and OpenRouter replaces Groq and OpenAI

Owner decisions, 2026-11-20 (after the Voice Arena evals, PRs #322–#332):
- Cleanup after transcription is the biggest measured win (+15–25 ZER points on every engine). Ship it.
- One cloud provider: **OpenRouter**, with the user's own key (users pay). **Remove Groq and OpenAI**
  outright: there are no real users yet, so no dual-provider period.
- Cloud default: speech `openai/gpt-4o-mini-transcribe`, cleanup `z-ai/glm-5.3-flash` (ZER 88.1 on the
  public set, ~$0.68 per 1,000 dictations). Fallback and planned replacement: speech
  `mistralai/voxtral-mini-3b-2507` (84.1 with GLM). gpt-4o-mini-transcribe shuts down 2027-02-26, so the
  models must be data, not code.

Evidence and sources: `/Users/gauri/vocet-screens/u9/model-features.md` (OpenRouter STT behaviour, ZDR,
prompt forwarding), PR #332's `eval/voxtral-omni/REPORT.md`, PR #327's `eval/cleanup-offline/REPORT.md`.

## Scope

1. **Cleaner port** (`crates/ports`): text in → cleaned text out, with a typed error. Deadline and
   cancellation live in `crates/app`; the guard (pure) lives in `crates/core`. Cleanup runs inside the
   existing dictation job, after transcription and before the cursor read and paste
   (`crates/app/src/pipeline.rs`).
2. **Prompt and guard**: port from branch `exp/groq-cleanup` (draft PR #324):
   `crates/transcribe/src/groq_cleanup.rs` (guard: `judge`, `is_echo`, numbers/links/names checks,
   `parse_reply`) and `groq_cleanup_prompt.rs`, but with **prompt v4**: the exact text of
   `eval/cleanup-offline/prompts/v4.txt` on branch `eval/cleanup-offline` (PR #327). Prompt v1 derives
   from Blurt (MIT): keep or add the NOTICE credit. Keep the Rust tests; add tests for v4's rules.
3. **Fallback, never fail**: if cleanup times out (default 1.5 s, a setting constant), errors, or the guard
   rejects the reply, paste the raw transcript. A timed-out request is cancelled. Log the reason at debug
   level only (no transcript text at info level).
4. **OpenRouter provider** (`crates/transcribe`, reuse `openai_compat.rs` where it fits):
   - Speech: `POST https://openrouter.ai/api/v1/audio/transcriptions` (see model-features.md §1 for the
     body format and normalised params). Send `prompt` only where OpenRouter forwards it.
   - Cleanup: `POST /api/v1/chat/completions`, reasoning effort low for GLM.
   - Privacy filters on every request: cleanup `provider: {zdr: true, data_collection: "deny"}`; speech
     `provider: {data_collection: "deny"}` (gpt-4o-mini-transcribe has no ZDR route; OpenAI does not train
     on API data). Fail closed if the filters are rejected.
   - Send `HTTP-Referer: https://vocetlabs.com` and `X-Title: Vocet` for app attribution.
   - Errors typed: invalid key (401), out of credits (402), rate limited (429), no eligible route,
     provider error (5xx), timeout. 402 surfaces "Add credits on OpenRouter"; others reuse U1's sentences.
5. **Model catalog as data** (`crates/core`): a bundled table/file with id, role (speech/cleanup), display
   name, price note, languages, shutdown date, prompt support, privacy filter. Defaults above; Voxtral
   Mini as the speech fallback when the default route returns "no eligible route" or 5xx.
6. **Remove Groq and OpenAI**: delete the providers, their key-test paths, settings UI and copy; Keychain
   account `openrouter-api-key` replaces `groq-api-key`/`openai-api-key`. **Settings migration**: a
   saved `"groq"`/`"openai"` provider (and any unknown value) maps to OpenRouter instead of failing
   deserialisation of the whole file; every other preference survives (closes #328). Old Keychain items
   are left alone (never read or copied). The local engine is unchanged in this milestone.
7. Settings UI: "Your OpenRouter key" replaces the Groq/OpenAI choice (paste field + key test for now;
   Q3 adds "Connect OpenRouter"). Show which speech and cleanup models are used.
8. Telemetry: the closed `Event` enum gets `provider: openrouter` and a `cleanup` outcome
   (applied / fallback_timeout / fallback_guard / fallback_error), never text.
9. Docs: `docs/privacy.md` and the site's privacy lines say what Cloud mode sends where (audio via
   OpenRouter to OpenAI; text via OpenRouter to a zero-data-retention GLM host; OpenAI doesn't train on
   API data and may keep logs up to 30 days). Q5 rewrites the full policy; here only make nothing false.

Out of scope: Connect-OpenRouter OAuth and credit display (Q3), local model changes (Q4), custom
dictionary and app context (later), Vocet Cloud.

## Acceptance criteria

1. [auto] Unit tests: guard (ported cases + v4 rules), prompt text equals v4 byte for byte, settings
   migration (groq/openai/unknown → openrouter, other preferences kept), catalog defaults and fallback.
2. [auto] Pipeline tests with fakes: cleaned text is pasted; timeout, error and guard rejection each paste
   the raw text; a timed-out cleanup is cancelled and doesn't delay the next dictation.
3. [auto] OpenRouter client tests against a local HTTP fake: request bodies include the privacy filters
   and attribution headers; 401/402/429/5xx/no-route map to typed errors; speech falls back to Voxtral on
   no-route/5xx; the key never appears in logs or errors.
4. [auto] No Groq/OpenAI code paths, settings or UI copy remain (grep), except the migration.
5. [auto] `scripts/gate.sh` passes; e2e scenarios updated (the mock transcriber still drives them).
6. [manual] Lead: with the owner's OpenRouter key in the VM (opt-in real-API test, like the old Groq one),
   dictate into TextEdit: cleaned text pasted; note key-up-to-paste time.
