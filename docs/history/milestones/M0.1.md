# M0.1 — Repo, Cargo workspace and Tauri/Vite scaffold

## Goal

An empty but buildable project with the layout from the build plan, so later
milestones only add code.

## Scope

- Cargo workspace at the repo root with the five library crates
  (`crates/core`, `crates/ports`, `crates/platform`, `crates/transcribe`,
  `crates/app`) and the Tauri shell in `src-tauri/`.
- `rust-toolchain.toml` pinning the Rust version; `.nvmrc` and `engines`
  pinning Node 24.
- Vite + React + TypeScript frontend in `src/`, wired into Tauri.
- Tauri 2 shell: one window, strict CSP, a `default` capability with only
  `core:default`, app icons.

## Out of scope

Lints, hooks, coverage and CI (M0.3); engineering docs and agent
definitions (M0.2); any app behaviour (M1.1 onward). Crates have no
dependencies on each other yet: each edge is added by the milestone that
first uses it, so `cargo machete` stays clean.

## Acceptance criteria

1. [auto] `cargo build --workspace` succeeds with the pinned toolchain.
2. [auto] `cargo fmt --all --check` passes.
3. [auto] `cargo clippy --workspace --all-targets -- -D warnings` passes.
4. [auto] `npm ci && npm run build` (type-check + Vite build) succeeds on Node 24.
5. [auto] `npm run tauri build -- --debug --bundles app` produces
   `dictation-app.app`.
6. [auto] `core`, `ports`, `transcribe` and `app` declare
   `#![forbid(unsafe_code)]`.
7. [manual] Lead: the app opens a window titled "dictation-app" when run
   with `npm run tauri dev`.
