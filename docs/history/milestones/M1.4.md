# M1.4: global hotkey and Accessibility

## Goal

Detect hotkey press and release system-wide on macOS.

## Scope

- `core::hotkey_spec`: parse/format strings like `RightAlt`, `Ctrl+Shift+Space`; reject invalid combinations.
- `platform::hotkey` using `handy-keys`; default modifier-only Right Option.
- `platform::permissions::macos`: Accessibility check (and prompt).
- Secure Input detection; a warning event while it's on.

## Out of scope

- UI for changing the hotkey (M3.4). Windows.

## Acceptance criteria

1. `[auto]` `hotkey_spec` unit tests: round trip, invalid combinations rejected.
2. `[auto]` Hotkey adapter maps OS key events to Pressed/Released (tested with a fake event stream where possible).
3. `[manual]` Run a debug binary: holding Right Option logs Pressed, releasing logs Released, in any app.
4. `[manual]` Without Accessibility, the app reports PermissionMissing instead of failing silently.
5. `[manual]` With a password field focused, the Secure Input warning is logged; Right Option still works.

Every milestone also needs: the gate green, coverage at or above thresholds, `Tester: PASS` and `Reviewer: APPROVED` on the PR.
