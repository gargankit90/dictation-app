# G2: Stop running the same checks twice, close the Mac CI gap

From the Lead, 2026-11-05, revised after Codex's independent opinion on the first plan.
Changes `scripts/gate.sh`, `.github/workflows/ci.yml` and the docs only; the guards stay as they are.

## Acceptance criteria

1. **[auto] Successful-run reuse.** After `scripts/gate.sh` passes in full it records a receipt, and a later run on the identical input is skipped with a clear message. The key covers the tree (clean, untracked non-ignored inputs included; a dirty tree never reuses or writes a receipt), the gate script's own content, OS and architecture, Rust, Node and check-tool versions, relevant env flags and profiles, and dependency install state. Written atomically, only after full success; a failure or interruption writes none. Expires after a few hours. Stored outside git, per worktree. CI never reads or writes a receipt. `scripts/gate.sh --full` ignores receipts. Every invalidation is tested without running the expensive checks.
2. **[auto] Mac CI gap.** The required `Platform crate (macOS)` job also runs workspace clippy, workspace nextest and workspace doctests with `DICTATION_NO_LAUNCH=1`, keeping the standalone platform checks and vendor tests. Job names unchanged. The misleading "macOS minutes cost 10x" comment is fixed. The job's new runtime is measured and reported, and the PR says what stays only on the owner's Mac (coverage, shell self-tests).
3. **[auto] Plain-prose shortcut.** When every changed file against the merge base of `origin/main` is ordinary Markdown on a short allowlist, the gate runs only formatting, spelling and link checks. Any unknown path, failed diff, missing `origin/main`, shallow history, detached HEAD, several merge bases, dirty tree or empty diff runs the full gate, with the reason printed. Deletions and renames count. Base, candidate, mode and reason are printed. Tested with fixtures.
4. **[auto] Tag pushes** get no special case: reuse applies only when a receipt matches.
5. **Docs** (`AGENTS.md`, `.claude/agents/developer.md`, `docs/ENGINEERING.md`, comments in `gate.sh`) describe what really happens; the rule stays "gate before pushing".
6. **Evidence:** one full run before and one after on this Mac, the second-run reuse and the prose-only case, with the load noted.

Not in this milestone: wider path-based selection, moving self-tests off the local run, parallelising.
