# F1: tests never touch the host

Bug found by the owner: since E1 (#225), every full test run on a Mac opens a
real browser tab at `github.com/gargankit90/dictation-app/issues/new?...` and
raises a Keychain prompt ("dictation-app wants to use your confidential
information stored in com.dictationapp.desktop"). The commands test
`the_settings_window_may_invoke_all_app_commands` invokes `open_issue`, which
calls `dictation_platform::reveal::open_url` (the real `open`), and its
fixture builds the production `Config` on the real `KeychainSecretStore`.

## Acceptance criteria

1. [auto] Opening URLs and revealing folders go through an injectable opener
   (port/trait) with a recording fake in tests; production uses the real one.
   The commands test asserts the fake recorded the URL.
2. [auto] Safety net: under `cargo test`/nextest (cfg(test) in the crate, or
   `DICTATION_NO_LAUNCH=1` set in `.config/nextest.toml` and `scripts/gate.sh`)
   the real opener refuses to spawn and returns an error. Same for "Reveal
   log".
3. [auto] Check the rest of the suite for other real side effects on the host
   (open, osascript, say, afplay, notifications, Finder reveal, NSWorkspace,
   login items, Keychain writes outside fakes) and route them through fakes;
   list what was checked in the PR.
4. [auto] Verify: run the full gate with a temporary wrapper `open` first on
   PATH that logs any invocation; the log stays empty.
5. [auto] Gate passes; hosted CI green.

Scope addition (top priority): tests must never touch the real Keychain or the
real settings/config/models/log directories.

6. [auto] Every test path that reaches the real `SecretStore`/keyring or the
   real app-data paths uses a fake store and a temp dir (the commands fixture
   `app_with_windows` first).
7. [auto] Safety net: in test builds or with `DICTATION_NO_LAUNCH` set, the
   keyring-backed store refuses (returns an error), so a forgotten fake fails
   loudly instead of prompting.
8. [auto] Verify: after the gate, no Keychain prompt appeared and the real
   app support directory and settings file are unchanged (mtimes compared).
