Only an item carrying `com.dictationapp.session` is excluded, as a whole item, so a stale transcript cannot be restored with its session type stripped. Mixed stale/other-item snapshots retain the other item.

```text

```

In an external copy of the adapter, substituting the exact round-1 `snapshot_items` algorithm makes both the marked-item and stale-session regressions fail (one failure each, exit 101). Thus these tests detect the old privacy defect and stale-transcript restoration, rather than merely checking the new helper.

### M1 — Fixed

At `crates/platform/src/insert/macos.rs:290`, all saved items, NSData copies, protocol conversions and the NSArray are built before the final ownership check at line 313. The shared write lock covers that check and commit; dictation writes also read their change count while holding it. The test hook runs before acquiring that lock, so the deterministic competing write cannot deadlock with it.

Re-ran the round-1 128 MiB/32-representation reconstruction with a competing fabricated copy scheduled 8 ms after restoration began:

```text
RACE: competing_copy_completed=true
RACE: restore_returned=false duration_ms=23 competing_copy_preserved=true
```

The deterministic regression `a_copy_while_the_restore_is_built_is_left_alone` passes. Removing only the final ownership check in the external copy makes that same test fail (exit 101), reproducing the old check-before-construction behavior. AppKit's residual cross-process check/clear race remains explicitly documented at lines 306–311; this fix closes the avoidable allocation/conversion window and serializes this adapter's writers, without claiming an atomic cross-process transaction.

### N1 / #79 — Fixed

All Cocoa clipboard entry points and `MacPasteKeys::paste` now enter local autorelease pools. The delegation from `restore_if_unchanged` reaches the pooled snapshot restore. Values returned across pool boundaries are owned Rust strings, vectors, markers, errors or booleans; no autoreleased borrow escapes. Retained Cocoa construction/results are used and dropped within the relevant closure.

Re-ran the round-1 worker-thread memory probe, with no caller-supplied pool, under `OBJC_DEBUG_MISSING_POOLS=YES`: **24 snapshot calls, zero missing-pool diagnostics**, compared with 199 in round 1. RSS was 25,392 KiB before and 84,848 KiB after; this probe establishes absence of missing-pool diagnostics, not a bound on allocator/cache residency.

Existing immutable AppKit constant accesses remain correctly justified. No new unsafe production operation was introduced.
