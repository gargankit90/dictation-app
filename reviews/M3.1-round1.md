# Reviewer: CHANGES REQUESTED

**PR #67 – M3.1 retry policy and mock transcriber**

**Summary**: The new retry implementation is pure and well‑tested, and the mock transcriber correctly models async behaviour. However there are several issues that must be addressed before approval:
- Duplicate flag parsing in the Tauri layer (critical).
- Edge‑case handling in jitter calculation (high).
- Missing documentation and minor clippy warnings.
- A few tech‑debt items.

**Focus checklist items verified**:
- Core purity (no I/O, injected clock/RNG) – ✅
- Backoff arithmetic overflow handling – ✅
- Jitter distribution bounds – ✅
- `SplitMix64` correctness – ✅
- `MockTranscriber` async correctness, cancellation safety – ✅
- `#![forbid(unsafe_code)]` in transcribe crate – ✅
- `thiserror` usage – ✅
- No `unwrap/expect/panic` outside tests – ✅
- Pedantic clippy passes – ✅ (except allowed warning noted below)
- Public API has doc comments – ❌ (missing for several items)
- Dependency rules (core has no workspace deps) – ✅

## Findings

### Blocker (Critical)
| File | Line | Finding | Suggested fix |
|------|------|---------|----------------|
| src-tauri/src/lib.rs | 77‑88 | Flag parsing (`flags::parse`) is performed twice – once in the single‑instance plugin callback and again in `setup`. This can lead to inconsistent handling of `--transcriber` on a second launch and overlaps with PR #66 (M2.2). | Consolidate parsing to a single call (e.g., parse once in `main` and pass the resulting `LaunchFlags` to both the plugin and `setup`). Emit the "--transcriber only applies when the app starts; ignored" warning only once. |

### High
| File | Line | Finding | Suggested fix |
|------|------|---------|----------------|
| crates/core/src/retry.rs | 101 | `delay_after` computes `cut = self.jitter.clamp(0.0, 1.0) * rng.next_unit().clamp(0.0, 1.0);` then uses `backoff.mul_f64(1.0 - cut)`. Because of floating‑point rounding `cut` can be > 1.0, resulting in a negative multiplier. | Clamp `cut` again: `let cut = (self.jitter.clamp(0.0, 1.0) * rng.next_unit().clamp(0.0, 1.0)).min(1.0);` |
| crates/transcribe/src/mock.rs | 84‑85 | `lock` unwraps a poisoned mutex with `unwrap_or_else(PoisonError::into_inner)`, silencing poisoning. | Propagate the poisoning (`self.state.lock()?`) or log a warning before returning the inner guard. |

### Medium
| File | Line | Finding | Suggested fix |
|------|------|---------|----------------|
| crates/core/src/retry.rs | 82‑84 | Missing doc comments for `RetryPolicy::backoff` and `Retry::failed` describing semantics (e.g., treatment of `max_attempts == 0`). | Add `///` documentation describing the behavior and edge‑case handling. |
| crates/transcribe/src/mock.rs | 41‑45 | Public builder methods (`with_delay`, `failing_next`, `always_failing`) lack documentation. | Add doc comments explaining their effect and that they return a new configured instance. |
| crates/core/src/retry.rs | 43 | Unnecessary `#[allow(clippy::cast_precision_loss)]` on the conversion of the top 53 bits to `f64`. The cast is exact. | Remove the `allow` attribute. |

### Low / Tech‑debt
| File | Line | Finding | Suggested fix |
|------|------|---------|----------------|
| crates/core/src/retry.rs | 190‑202 (tests) | Uses `Duration::MAX` which may be unstable on older toolchains. | Replace with a large but stable value, e.g., `Duration::from_secs(u64::MAX / 1_000_000)`. |
| crates/tauri/src/flags.rs | 90‑96 | Manual construction of ignored flag strings for unknown transcriber names. | Introduce a helper `fn ignore_unknown(flag: &str, arg: &str)` to centralize the logic. |

## Recommendations
1. Refactor flag handling as described in the blocker finding.
2. Apply the jitter clamp fix.
3. Add the missing documentation and remove the unnecessary clippy allow.
4. Address the tech‑debt items at a convenient time (they do not block the PR).
5. Re‑run the quality gate after changes.

Once the critical and high‑severity items are resolved, the reviewer can approve the PR.
