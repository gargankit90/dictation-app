## Also checked
- The read is bounded: `CursorReader::preceding` wraps the blocking read in `tokio::time::timeout` (200 ms by default). Removing the timeout fails the 50 ms/800 ms test, so a hung app cannot delay the paste.
- The reader never runs for secure fields: in `crates/platform/src/cursor/macos.rs`, Secure Input and the `AXSecureTextField` subrole return `SecureField` before `AXSelectedTextRange` or any string is read. No unit test (a host test would read the developer's focused app, which the Developer avoided on purpose); the real adapter is covered only by `e2e_smart_space`, and it has no password-field scenario. If the `AXSubrole` read itself fails, the field is treated as non-secure and read (fail-open on that one attribute). See the issue below.
- Pipeline reads only when there is text to paste (dropped/failed transcript: 0 reads).
