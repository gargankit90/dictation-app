## How criterion 3 was driven

The `cua-vm` MCP server dropped its connection on the first call (`Connection closed`). As the brief allows, I drove the VM's own `cua-driver` 0.37.0 over ssh instead: `ssh lume@<vm> ~/.local/bin/cua-driver call <tool> <json>`. `cua-driver` has Accessibility and Screen Recording in the VM. The status item's AX element was unresolved, so the clicks were desktop-scope pixel clicks with `delivery_mode: foreground`. That moves the VM's own pointer, not the host's. Nothing touched the owner's screen.

Note for whoever drives the VM next: the screen is 960×720 pt at scale 2. `click` with `scope: "desktop"` takes full-size capture pixels (1920×1440): tray icon at (1466, 22), Quit at (1562, 126). This only holds after a `get_desktop_state` with `max_image_dimension: 0`. A downscaled capture in a separate `call` maps differently: my first click opened Finder's Help menu.
