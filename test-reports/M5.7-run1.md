## Failures

**Major: `no_fixture_left` is machine-global, so concurrent runs fail each other, and CI.**
In `tests/e2e/test-runner.sh`, `no_fixture_left` uses `pgrep -fx '/bin/sleep 602'`,
which matches the `/bin/sleep 602` of any other test-runner run on the machine. Every
run sleeps 602 in its #164 cases, so overlapping runs (a Developer's push gate, CI,
a Tester) see each other's.

Repro: `for i in 1 2 3 4; do bash tests/e2e/test-runner.sh > out$i.log 2>&1 & done; wait`,
then `grep FAIL out*.log`. Two rounds of four: all 8 runs failed, with 5-6 times
`FAIL: and leaves no fixture process` (88-89 of 94 passed). Two at once passed once;
a lone run passes 94/94. The PR's own CI run hit it with two failures, so it already
turns the gate red.

Expected: a run checks only its own processes. Suggested fix: give each cleanup case a
unique stub argument (for example derived from `$$` or the case's `$dir`) and match
that instead of the fixed 602.
