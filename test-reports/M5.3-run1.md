## Failures

**Unwritable log directory stops the app (major).**

1. In the VM: `rm -rf ~/Library/Logs/com.dictationapp.desktop`, then `chmod 555` the recreated dir (or put a file at that path).
2. `open -n -g ~/Applications/dictation-app.app`.
3. Expected: the app runs without a log file (stderr only). Actual: no process (`pgrep` count 0); the control run with a writable dir gives count 1.

Cause: `src-tauri/src/lib.rs:257`, `logging::init(&log_dir).context("could not start logging")?`, propagates the error out of `setup`. `RotatingFile::open` fails if the dir can't be created or read. Suggested fix (Developer): on failure fall back to a stderr-only subscriber and carry on, still managing `LogDir`; add a test.
